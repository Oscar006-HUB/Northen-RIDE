# North Link (Northen-RIDE)

Static website for North Link, an eco-friendly student transport and ride-booking service.

**Live site:** https://oscar006-hub.github.io/Northen-RIDE/

## Pages
- **Home** (`index.html`)
- **Book Ride** (`book-ride.html`) — choose a bus and book a seat
- **About Us** (`about.html`)
- **Contact** (`contact.html`)
- **Terms** (`terms.html`)

## Tech stack
HTML, CSS and vanilla JavaScript, hosted on GitHub Pages.

## Running locally
No build step — clone the repo and open `index.html` in a browser.
